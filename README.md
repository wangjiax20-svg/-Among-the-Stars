# 群星之间 · Among the Stars

以星空寻找为核心的宠物纪念小工具，手机竖屏优先。

**体验地址：[打开群星之间](https://among-the-stars.cool-prawn-6472.chatgpt.site)**

## 当前版本：免登录

- 三步创建：认识TA → 布置星球（地表、装饰、星环）→ 添加宠物贴纸（可跳过）。
- 横向观星手册、望远镜寻找、探望及持续追加带日期的信件。
- 修改资料、星球与贴纸，不改变已有星球的位置和信件。
- 完整手册 JSON 备份与恢复；同一 ID 的不同版本保留副本。
- 1080 × 1440（3:4）星球分享图片；留言默认不包含，需主动勾选。
- 复制工具链接；不自动上传用户记录或生成公开个人星球链接。

## 数据与隐私

本版不提供账户、服务器保存或跨设备自动同步，已经移除演示登录。数据保存在当前网站域名下的浏览器 localStorage。清理浏览器、更换设备或域名会导致原数据不可见，请先在观星手册点「保存备份」，下载「完整观星手册」，再在新浏览器恢复。

完整手册备份包含已保存的宠物资料、照片、星球布置、预览图与全部留言；不包含未完成的创建草稿。工作室中的「作品文件」只保存单颗星球外观，不能替代完整手册备份。备份文件请妥善保管，不应提交到公开仓库。

新访客的个人手册为空；「今夜所见」为预置示例，不是其他访客上传的内容。历史版本中的示例文字仍可在源码中找到。照片处理在本机执行；自动抠图会按需下载外部模型，网络或设备条件不足时可以上传相册中已有的透明贴纸。

## 本地运行

在此目录执行：

```sh
python -m http.server 8000
```

打开 http://localhost:8000 。这是静态网站，无需构建。不要直接用 file:// 打开，以免动态模块与照片处理受限。

## GitHub Pages

本仓库根目录可直接用于静态托管，资源均使用相对路径。在仓库 Settings → Pages 中选择 Deploy from a branch、main 和 / (root)，保存后以 GitHub 返回的实际地址为准。也可用其他静态托管服务。

仓库上传与 Pages 开通是两件事；本项目的已部署体验地址见上文。

## 文件说明

- `index.html` / `app.js` / `styles.css`：创建、手册、望远镜、留言与分享。
- `studio.html` / `studio.js` / `studio.css`：星球编辑器。
- `collage-planet.js`：统一拼贴星球渲染。
- `notebook-data.js`：完整备份格式、校验与无覆盖合并。
- `pet-stickers.js`：本机照片读取、白边、裁切与抠图。
- `assets/`：星球、背景与贴纸素材，PNG 素材已无损转换为 WebP。
- `vendor/`：现有第三方依赖及其原始许可证。
